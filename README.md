### 🧭 About Me

I'm a Software engineer focused on **distributed, event-driven systems** — the kind that move messages reliably at scale. At **The Legal Leads**, I built Cloud AI Workflows, Distributed Systems and event driven backend platforms, using languages, frameworks and techstack like Python, AWS, Apex (Java-based),Gemini and Grok LLMs, RDS PostgreSQL, Aurora, and NoSQL Databases like MongoDB and DynamoDB. Worked with React, TypeScript and Next.JS based Applications and interfaces to enhance UI/UX.

Previously, I helped migrate a monolithic financial-services platform (32K+ accounts) into containerized, service-oriented components with Python, C++, React, TypeScript, on Docker and Kubernetes with Jenkins CI/CD pipeline.
Enhanced Security with JWTs, OAuth 2.0, RBAC controls.

- 🔭 Currently building **[Wanderful](https://github.com/mahijeetreddy/Wanderful)** — a fault-tolerant LLM orchestration layer across 5+ providers
- 🎓 M.S. Computer Science, Cal State Fullerton — where I also taught distributed-systems architecture labs
- 📫 Reach me at **mahijeetreddygaddam@gmail.com**
